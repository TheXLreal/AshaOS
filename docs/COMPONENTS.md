# Компоненты, службы и лицензии

Этот список помогает понять, что запускается и почему. AshaOS не использует
облачный сервер для передачи звука и не добавляет телеметрию.

| Компонент | Зачем используется |
| --- | --- |
| Android Bluetooth / ASHA | Сопрягает слуховой аппарат, кодирует звук и отправляет его по стандартному Bluetooth LE каналу ASHA. |
| Audio-Asha на телефоне | Показывает адрес, режим и статус, держит активный сеанс, принимает обычный UDP в режимах AudioTrack. Требует разрешения уведомлений для фоновой службы. |
| AshaOS Direct в модуле Bluetooth | Принимает PCM по TCP или UDP от ПК в очередь перед кодировщиком ASHA. Не реализует отдельный GATT-сервис для слухового аппарата. |
| ADB | Только для Direct: клиент читает метку текущего сеанса через разрешённый `dumpsys bluetooth_manager`. Звук по ADB не идёт. Отладку USB/сети включает владелец телефона. |
| Windows WASAPI | Захватывает системный звук; по желанию поддерживает Windows audio engine активным во время тишины. |
| Linux PipeWire/PulseAudio | Клиент использует `pactl` и `parec`/`pacat` для монитора выбранного выхода. Qt6 рисует интерфейс и значок трея. |
| USB-модем, Wi-Fi, Bluetooth PAN | Локальная IP-сеть между ПК и телефоном. Bluetooth PAN не означает прямое подключение ПК к слуховому аппарату. |

Direct-записи содержат случайную метку сеанса. Она отсеивает данные от старого
сеанса, но **не является полноценной криптографической аутентификацией или
сквозным шифрованием звука**: метка видна в пакетах локальной сети. Используйте
только доверенный USB или локальную сеть. Стандартное Bluetooth-соединение от
телефона до слухового аппарата защищается средствами Android и самого ASHA.

Собственные дополнения AshaOS имеют свободную лицензию
[Apache 2.0](../LICENSE) и уведомление об авторстве в [NOTICE](../NOTICE.md).
Исходный Android/LineageOS код сохраняет свои заголовки и лицензии. Это нужно,
чтобы пользователи могли законно распространять и изменять проект и знали,
кто создал отдельные его части. Лицензия на программный код не даёт прав на
чужие товарные знаки или проприетарные `vendor`-файлы.
