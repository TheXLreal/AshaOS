# AshaOS Beta 1.7

[English](README.en.md) · [Загрузки](../../releases)

AshaOS — экспериментальная прошивка Android 16 на основе LineageOS 23.2 для
слуховых аппаратов с поддержкой ASHA. Этот репозиторий содержит приложение для
телефона, исходники клиентов Windows и Linux, дерево продукта Pixel 5 и GSI,
а также небольшие патчи к Bluetooth и Android framework. Готовые файлы находятся
в разделе **Releases → AshaOS Beta 1.7**, а не в истории Git.

**Статус:** Beta. Проблема возникает с микро прерыванием со звуком. Хотя на виндовс меньше прерываний, но на линукс больше прерываний. GSI не сработало на Pixel 5. Сейчас пока не возникаю прерываний на виндовс

В [релизе](../../releases) находятся:

| Файл | Назначение |
| --- | --- |
| `lineage-23.2-20260923-UNOFFICIAL-ashaos_redfin-direct-network.zip` | OTA Android 16 только для Pixel 5 с совместимой AshaOS |
| `boot.img`, `dtbo.img`, `vendor_boot.img` | Разделы Pixel 5 из этой OTA; не полная прошивка |
| `windows-ashaos-1.7.exe` | Клиент передачи звука Windows |
| `ashaos-linux_1.7.0_amd64.deb` | Клиент Ubuntu/Debian для AMD64 |
| `AshaOS-GSI-Android16-arm64.img.gz` | Экспериментальный ARM64 `system.img` для DSU/разработки |
| `SHA256SUMS.txt` | Контрольные суммы загрузок |

Каждый файл релиза меньше 2 ГиБ. Несжатая GSI в GitHub не загружается: она
превышает этот предел. Загрузка GSI в виде `.gz` занимает около 1,2 ГБ, OTA —
около 1,3 ГБ. Клонирование репозитория не скачивает эти образы.

Три отдельных образа уже входят в OTA. Их размеры и SHA-256 совпадают с
разделами в manifest `payload.bin`. Не смешивайте их с другой сборкой и не
прошивайте по отдельности как замену установке всей системы.

## Как работает Direct

ПК захватывает системный звук и передаёт PCM на **телефон** по TCP или UDP
через USB-модем, Wi-Fi или Bluetooth PAN. На телефоне модифицированный модуль
Bluetooth принимает кадры в локальную очередь перед штатным кодировщиком ASHA.
Он обходит обычный путь воспроизведения PCM через Android AudioTrack; при этом
системное соединение ASHA остаётся активным. Android по-прежнему отвечает за
кодирование G.722, сопряжение, управление слуховым аппаратом, L2CAP и шифрование
Bluetooth. Мы не прошиваем аппарат и не создаём собственный GATT-сервис как у
отдельной платы Nordic/Pico. Bluetooth PAN здесь лишь один из способов доставить
сетевые пакеты с ПК до телефона; он делит радио с выходным ASHA и может работать
хуже USB или Wi-Fi.

Для Direct-клиента нужен разрешённый ADB, чтобы прочитать одноразовый ключ
текущего сеанса из `dumpsys bluetooth_manager`. Сам звук идёт по выбранной
локальной сети, а не через ADB и не через сервер в интернете. Три режима
`UDP / AudioTrack` оставлены для сравнения и работают через обычный звуковой
тракт Android. Протокол и IP:порт в клиенте должны совпадать с приложением
Audio-Asha на телефоне. По умолчанию Direct TCP и поддержание системного звука
включены, буфер телефона — 20 мс, предбуфер ПК — 40 мс, порог тишины — −80 dBFS.
Значения подсказок в клиентах показывают текущие настройки.

Задержка зависит от телефона, сети и слуховых аппаратов. По субъективному
наблюдению автора Wi-Fi и Bluetooth могут добавлять примерно 50 мс по
сравнению с USB; это не гарантированная характеристика и не отдельное свойство
GSI.

## Установка

(хм.. обычно сначала "adb reboot bootloader, затем unlock, грузить boot, dtbo, vendor_boot)
Chatgpt -> **Обновление Pixel 5.** Используйте OTA только на `redfin` с уже установленной
совместимой AshaOS. Сделайте резервную копию, зарядите телефон, откройте AshaOS
recovery → **Apply update → Apply from ADB**, затем на ПК:

```sh
adb devices
adb sideload lineage-23.2-20260923-UNOFFICIAL-ashaos_redfin-direct-network.zip
```

На Windows перед командой можно выполнить `adb reboot recovery`, пока телефон
загружен и виден как `device`. После успешной установки выберите **Reboot system
now**. Переход со стока или другой прошивки этим OTA не проверен; при ошибке
подписи остановитесь и сохраните текст ошибки.

**Windows.** Запустите `windows-ashaos-1.7.exe`; установите официальные
[Android Platform Tools](https://developer.android.com/tools/releases/platform-tools),
чтобы `adb devices` видел разрешённый телефон. Выберите на телефоне и ПК один
режим, включите соответствующий USB-модем/Wi-Fi/Bluetooth PAN, введите IP:порт
с телефона и нажмите Start. Закрытие окна оставляет клиент в трее.

**Ubuntu/Debian.** Установите пакет через
`sudo apt install ./ashaos-linux_1.7.0_amd64.deb`. Клиент захватывает монитор
выбранного выхода PipeWire/PulseAudio; режим, IP:порт и ADB настраиваются так
же, как на Windows. Реальная работа пакета пока требует проверки пользователями.

**GSI.** Это только системный раздел: ядро, `vendor`, модем и прошивка аппарата
остаются от устройства. Проверьте ARM64/Treble, динамические разделы,
совместимость `vendor` с Android 16 и способ возврата к старой системе. Для
неразрушающего эксперимента используйте [DSU](https://developer.android.com/topic/dsu)
на поддерживаемом устройстве. После проверки SHA-256:

```sh
adb push AshaOS-GSI-Android16-arm64.img.gz /storage/emulated/0/Download/
adb shell am start-activity \
  -n com.android.dynsystem/com.android.dynsystem.VerificationActivity \
  -a android.os.image.action.START_INSTALL \
  -d file:///storage/emulated/0/Download/AshaOS-GSI-Android16-arm64.img.gz \
  --el KEY_SYSTEM_SIZE 2381762560 \
  --el KEY_USERDATA_SIZE 8589934592
```

DSU может отклонить образ, подписанный не ключом производителя, либо не
загрузить его даже после установки. На Pixel 5 предыдущие попытки не дали
работающую GSI. **Не прошивайте эту GSI поверх единственной рабочей системы
без проверенного способа восстановления.** Для постоянной прошивки нет общей
команды для всех устройств; ориентируйтесь на [документацию AOSP](https://source.android.com/docs/core/tests/vts/gsi)
и инструкции именно вашей модели.

## Сборка и перенос на другие модели

[Пошаговая инструкция](docs/BUILDING.md) описывает исходник LineageOS 23.2,
применение патчей, сборку OTA/GSI и требования к дереву, ядру и `vendor`
другого устройства. AshaOS не может автоматически подставить драйверы любой
модели: для неё нужна отдельная проверенная конфигурация и собственная сборка.
